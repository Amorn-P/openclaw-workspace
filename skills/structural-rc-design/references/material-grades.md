## Common Rebar Layout Rules

- Main bars in beams: 2–6 bars per layer, clear spacing ≥ max(25mm, db)
- Stirrup hooks: 135° for seismic, 90° standard
- Splice length (tension Class B): 1.3 × Ld
- Development length Ld for DB20 in C25: ~650 mm (bottom bars)
- Column tie spacing: ≤ 16db_main, 48db_tie, min dimension
