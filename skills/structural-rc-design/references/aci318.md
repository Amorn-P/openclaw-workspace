## Flexure: Rectangular Sections

```
a = As × fy / (0.85 × f'c × b)
φMn = φ × As × fy × (d − a/2)
Rn = Mu / (b × d²)
ρ = (0.85 f'c / fy) × [1 − √(1 − 2Rn/(0.85 f'c))]
ρ_b = 0.85 β1 (f'c/fy) × [600/(600+fy)]
```

## Shear: Non-Prestressed Members (ACI 22.5)

```
Vc = 0.17 λ √f'c × bw × d              (ACI 22.5.5.1)
Vs_max = 0.66 √f'c × bw × d            (ACI 22.5.1.2)
s_max = min(d/2, 600 mm)               (ACI 9.7.6.2.2)
If Vs > 0.33√f'c bw d → s_max = min(d/4, 300 mm)
```
