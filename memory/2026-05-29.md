### Architecture Decision
- CommBoard: ESP32-S3 with PSRAM — WiFi, Blynk, Telegram, LoRa, LCD2004, SD, RTC(DS3231+DS1302), dipswitch, OTA
- CtrlBoard: ESP32 DOIT — relay FSM, Modbus to 5× relay slaves, safety, buzzer/LED
- Inter-board: RS485 via MAX13487, 115200 baud, custom binary CherryLink protocol
- CtrlBoard is standalone-capable (can run without CommBoard)
