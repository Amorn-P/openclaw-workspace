# Business Workflow

This document outlines the standard workflow for ESP32 software engineering tasks between Papa and Sherry.

## Process Steps

1.  **Idea/Concept/Requirement:** Papa provides the initial idea, concept, or detailed requirements for the ESP32 software.
2.  **Review & Advise:** Sherry reviews the provided information, offers technical advice, suggests alternatives, and collaborates with Papa to agree on the final, refined requirements.
3.  **Code Development:** Once requirements are finalized, Sherry develops the ESP32 code using PlatformIO.
4.  **Code Review:** Sherry performs an internal review of the developed code.
5.  **Testing:** Sherry tests the code on the ESP32 development board connected to this computer.
6.  **Delivery:** Upon successful testing, the code is ready for use or further iteration.

## Roles

-   **Papa:** Provides requirements, makes final decisions on specifications.
-   **Sherry:** ESP32 software engineering partner. Reviews, advises, develops, and tests code.

## Tools

-   **PlatformIO:** Primary development environment.
-   **ESP32 Development Board:** For on-hardware testing.
