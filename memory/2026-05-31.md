# 2026-05-31 — CherryOne v2.1.2 Field Test at Farm

## Session Summary
Field testing CherryOne ModbusHealth at the farm. New ESP32 module (MAC: ec:e3:34:db:3b:88) with replaced RS485 module. Multiple HW/SW fixes applied.

## Changes Made (v2.1.0 → v2.1.2)

### Bug Fixes
1. **bootRelaySafety()** — Added GPIO32 (pump LED) and GPIO33 (buzzer) to boot initialization. Prevents LED flicker and buzzer chirp during power-on before Task3 starts.

2. **Blynk slave alive timeout** — Extended from 10s to 30s. Farm WiFi drops cause brief Blynk disconnections; 10s was too aggressive, causing false slave-offline alerts on Blynk LEDs V82-V86.

3. **Internet check flapping** — Fail threshold raised from 2→5 consecutive failures before switching to Fast Mode. WiFi-disconnect immediate switch removed (now uses fail counter too). Prevents ping-pong mode switching on brief internet blips.

4. **platformio.ini** — Fixed `lib_extra_dirs` path from SKY → SAMBA user folder.

### Diagnostics Added
5. **Buzzer self-test** — 200ms beep on Task3 startup. Confirms GPIO33 + buzzer relay module hardware.
6. **Pump LED self-test** — 200ms blink on Task3 startup. Confirms GPIO32 + LED hardware.
7. **Serial LED state logging** — `[LED] Pump LED GPIO32 -> ON/OFF` on every state change. Helps distinguish code vs hardware issues.
